# 技能清单与技术栈

## 编程语言
- **Python**：主力语言，熟悉 pandas / numpy / FastAPI / LangChain
- **C 语言**：课程与课程设计使用（噪声检测系统、嵌入式）

## AI / 大模型
- **RAG（检索增强生成）**：文档切分、向量化、检索、带引用回答
- **混合检索**：BM25 + 向量 + RRF 融合
- **Agent**：工具调用（function calling）、记忆系统、多轮对话
- **MCP（Model Context Protocol）**：把能力封装成标准插件
- **Prompt 工程**：系统提示词、结构化输出（JSON Schema）
- **深度学习**：Transformer 情感分类（91.3%）、CNN、K-Means

## 工程能力
- **Web 服务**：FastAPI、Uvicorn、REST API
- **容器化**：Docker、docker-compose
- **测试**：pytest（13 个单元测试）
- **CI/CD**：GitHub Actions
- **版本管理**：Git / GitHub

## 数据与向量
- **向量库**：FAISS
- **检索**：BM25、余弦相似度、RRF
- **数据处理**：pandas、numpy

## 模型与 API
- **DeepSeek API**（OpenAI 兼容）
- **Transformer**（HuggingFace 生态）
