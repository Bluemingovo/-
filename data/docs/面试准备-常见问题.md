# 面试准备：常见问题与回答要点

## 关于项目

### Q1：你做的这个 RAG 项目，核心解决了什么问题？
纯向量检索对关键词类问题漏检严重；Agent 又会跨会话失忆。所以做了三件事：混合检索、分层记忆、MCP 封装。

### Q2：为什么用 RRF 而不是加权求和？
BM25 和余弦相似度的分数量纲不同，加权求和要调权重且不稳定；RRF 只依赖排名，不需要归一化，更鲁棒。

### Q3：你的评测集只有 20 题，55%→100% 可信吗？
诚实回答：20 题样本偏小，是方向性结论，不是统计显著结论。后续计划扩到 50~100 题并加置信区间。

### Q4：增量索引怎么做的？
按文件 mtime 检测变更，只重索引变更文件，避免全量重嵌入。

### Q5：记忆系统会不会记错？
短期按 session 隔离；长期由 LLM 提炼后写入，可人工校正；自主写入有 key 约束。

## 关于自己

### Q6：你的优势是什么？
能独立从 0 到 1 交付可运行的项目，且重视工程化（测试、CI、Docker、评测）。

### Q7：你的短板是什么？
学历和英语是短板，所以更依赖项目和工程能力来证明自己；也在持续补英语和底层知识。

### Q8：为什么想做 AI 应用开发？
喜欢“把模型能力变成能用的产品”，而不是只做模型训练；RAG/Agent 正好是落地层。

## 关于技术方向

### Q9：RAG 和微调怎么选？
知识频繁更新、要可溯源 → RAG；风格/格式/领域语言 → 微调；很多场景是两者结合。

### Q10：Agent 的记忆和 RAG 的检索有什么区别？
RAG 检索的是“文档知识”，记忆存的是“用户/对话事实”；两者都是上下文注入，但来源和更新频率不同。
