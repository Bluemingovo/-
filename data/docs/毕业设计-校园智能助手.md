# 毕业设计：基于 RAG 的校园智能助手系统设计与实践

## 选题背景
校园里信息分散（教务、社团、课程、办事流程），学生查信息成本高。用 RAG 把校园文档变成可问答的知识库，降低信息获取成本。

## 题目
《基于 RAG 的校园智能助手系统设计与实践》

## 核心内容
1. **系统架构**：复用 LLM RAG Agent 的架构（混合检索 + 记忆 + FastAPI）
2. **校园知识库**：教务通知、课程信息、办事指南、社团介绍
3. **实践验证**：真实校园用户试用（20~30 人、150 条问句、满意度问卷、bad case 迭代）
4. **论文结构**：背景 → 相关工作 → 系统设计 → 实现 → 实验与评估 → 总结

## 创新点
- 混合检索（BM25 + 向量 + RRF）在校园垂直场景的适配
- 真实用户试点数据（不是纯离线评测）
- 记忆机制支持个性化问答
